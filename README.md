# Hostel Management System — Frontend

A responsive React + Vite frontend for the Review 3 Hostel Management System.

## Included
- Dashboard
- Student Management
- Room Management
- Room & Bed Allocation
- Payments placeholder
- Maintenance placeholder
- Administration placeholder
- Search/filtering
- Add Student modal
- New Allocation modal
- Bed availability validation
- Cancel allocation
- Responsive mobile sidebar

## Run locally

```bash
npm install
npm run dev
```

Then open the URL shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files are generated in `dist/`.

## Important
This version is a frontend prototype with in-browser state and sample data. It is not connected to PostgreSQL/FastAPI yet.
